# 小牵项目版本档案

小牵是面向抖音内嵌旅行行程场景的产品设计项目。当前能核实的交付资料归入产品 **V1.1**。

| 产品版本 | 归档状态 |
| --- | --- |
| [V1.1](V1.1/) | 已归档项目背景、文档、原型、设计原图、流程与验收资料及设计核对台 |
| V1 / V1.0 | 尚无可核实的独立交付包。SRS 和需求分析报告均已同步至 V1.1。主档案和页面清单的 v1.0 是各自的文档修订号 |
| V2 | 主档案记载后续探索方向，尚无可核实的独立交付包 |

从 [V1.1 版本说明](V1.1/README.md) 查看资料用途和缺项。可用 [SHA-256 清单](V1.1/SHA256SUMS.csv) 核对归档资料。
